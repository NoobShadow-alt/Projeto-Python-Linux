# Projeto-Python-Linux
Projeto de aprendizagem de Python e Shell Script

Como executar o arquivo Shell Script (.sh)

Abra o terminal Linux.

Acesse a pasta onde o arquivo foi salvo.

Dê permissão de execução ao arquivo:

chmod +x calculadora.sh

Execute o programa:

./calculadora.sh

Informe os números solicitados e escolha a operação desejada no menu.

O script utiliza comandos Bash para receber dados do usuário, verificar a opção escolhida e realizar operações matemáticas.



Explicação do código Python

O programa em Python utiliza a função input() para receber os números digitados pelo usuário. A função float() converte os valores recebidos em números que podem conter casas decimais.

Uma estrutura de repetição while permite exibir o menu de operações até que o usuário escolha encerrar o programa.

As operações matemáticas são selecionadas conforme a opção informada:

Soma: adiciona os dois números.

Subtração: calcula a diferença entre os números.

Multiplicação: multiplica os valores.

Divisão: divide o primeiro número pelo segundo, verificando se o divisor é diferente de zero.

A função print() apresenta os resultados na tela. Uma opção de encerramento permite finalizar o programa.
